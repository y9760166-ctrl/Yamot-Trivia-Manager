\# Yemot HaMashiach Trivia Management API



מערכת API לניהול מודול הטריוויה הרשמי של 'ימות המשיח' דרך ה-IVR.



\## מבנה הקבצים

\- `index.js` - קוד ה-Server הראשי ב-Node.js/Express.

\- `ext.ini` - קובץ ההגדרות לשלוחה במרכזיית ימות המשיח.

\- `package.json` - תלויות הפרויקט.



\## שלבי העלאה ל-GitHub ואירוח:

1\. צרו Repository חדש ב-GitHub.

2\. העלו את הקבצים `index.js`, `package.json`, ו-`README.md`.

3\. חברו את ה-Repository לשירות אירוח חינמי לבחירתכם (כגון Render, Vercel, Railway, או Netlify).

4\. העתיקו את ה-URL של השרת שנוצר והדביקו אותו בפרמטר `api\_url` בקובץ `ext.ini`.

5\. העלו את קובץ ה-`ext.ini` לשלוחת הניהול במערכת ימות המשיח.
